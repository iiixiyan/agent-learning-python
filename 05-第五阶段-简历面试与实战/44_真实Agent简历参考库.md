## 为什么需要简历参考？

很多同学学完 Agent 开发，做完 Agent 项目，但是不知道怎么把它写到简历上。再就是写完简历也不知道自己写的怎么样，别人都是咋写的，做了啥 Agent 项目。

本文收集了 **10 份真实的 Agent 简历**，供大家参考。有两个目的：

1. **参考别人简历咋写的**，来写自己的简历
2. **看下别人都做了啥 Agent 项目**，用了啥技术，有啥功能

## 第十份：跨模态知识库 RAG

![简历](../IMG/2026-07-22_真实Agent简历参考库/17_公众号_Yi昭.webp)

### 项目亮点

| 技术点 | 说明 |
|--------|------|
| **跨模态检索** | Any2Any，文本、图片都能检索 |
| **多模态嵌入** | 用多模态嵌入模型把文本、图片都存到同一个向量空间 |
| **混合检索** | 向量 + 关键词的混合检索 |
| **短期记忆** | Redis 做短期记忆 |
| **长期记忆** | Milvus 做长期记忆，关键词 + 语义混合召回 |
| **Agent 评测** | 召回率、准确率等指标 |

**跨模态实现说明**：不是图片识别转文字然后做文字语义检索，而是用多模态嵌入模型把文本、图片都映射到同一个向量空间，实现真正的跨模态检索。

| 加分项 | 说明 |

| **Agentic RAG** | LLM 自主决策检索过程，比普通 RAG 更高级 |
| **知识图谱** | Neo4j 做推理式检索，技术含量高 |
| **多 Agent 协作** | 主从 Agent、意图路由，体现系统设计能力 |
| **Human in the Loop** | 人工介入机制，生产级项目必备 |
| **记忆系统** | Redis 短期 + Mem0 长期，体现 Agent 完整能力 |
| **评测体系** | 召回率、准确率、LLM as Judge，体现工程严谨性 |
| **权限控制** | 企业级项目必备，体现生产意识 |
| **业务系统整合** | Tool call 封装订单/CRM/工单系统，体现落地能力 |

### 简历避坑指南

| 避坑点 | 说明 |
|--------|------|
| **不要写太细** | 简历简洁清晰，突出重点亮点，不要堆砌细节 |
| **格式要清晰** | 高亮、加粗每一条的前面部分，让 HR 一眼看到亮点 |
| **要有量化指标** | 不要只说"做了XX"，要说"提升了XX%"、"准确率XX%" |
| **技术栈要匹配** | 写的技术要和岗位要求匹配，不要写不相关的 |
| **项目要有深度** | 不要只写"用了XX框架"，要写解决了什么问题、怎么优化的 |

## 学习要点

1. **知识库 RAG 是简历最常见项目**，但也很加分：混合检索（向量+关键词+Reranker）、Agentic RAG、权限控制都是亮点
2. **知识图谱（Neo4j）**能提升技术含量：实体关系建模、推理式检索、Text-to-SQL 表关系存储
3. **多 Agent 系统**体现系统设计能力：主从 Agent 路由、意图识别、Human in the Loop 人工介入
4. **记忆系统**是 Agent 完整能力的体现：Redis 短期记忆、Mem0/Milvus 长期记忆
5. **评测体系**是简历加分项：召回率、准确率、LLM as Judge、LangFuse 观测
6. **Agentic RAG**比普通 RAG 更高级：让 LLM 参与检索决策（查询改写、质量评估、条件重试）
7. **业务系统整合**体现落地能力：把订单/CRM/工单系统封装为 Tool call
8. **跨模态检索**是新兴方向：多模态嵌入模型把文本图片映射到同一向量空间
9. **简历要简洁清晰**：突出重点亮点，量化指标，格式清晰，不要写太细
10. **参考别人简历**：看别人做了啥项目、用了啥技术，扩展自己的思路和学习方向

## 扩展方向

- 学习如何写好技术简历（STAR 法则、量化指标、关键词匹配）
- 探索 Agent 项目的更多业务场景（金融、法律、教育、医疗）
- 学习 Agent 系统设计（多 Agent 协作、任务分解、冲突解决）
- 探索 RAG 高级技术（HyDE、Query2Doc、Self-RAG、Corrective RAG）
- 学习知识图谱构建（实体抽取、关系抽取、图谱融合、图谱推理）
- 探索多模态 Agent（图文理解、视频理解、语音交互）
- 学习 Agent 评测方法（人工评测、自动评测、LLM as Judge、A/B 测试）
- 探索 Agent 安全与对齐（Prompt 注入防护、输出审核、价值观对齐）
- 学习 Agent 部署与运维（Docker、K8s、监控告警、灰度发布）
- 探索 Agent 产品化（用户体验、交互设计、产品迭代、用户反馈）
