---

## 鉴权 vs 认证

| 概念 | 英文 | 说明 | 示例 |
|------|------|------|------|
| **认证** | Authentication | 你是谁？（验证身份，登录） | 用户名密码登录、短信验证码、第三方登录 |
| **鉴权** | Authorization | 你能做什么？（验证权限，访问控制） | 管理员可以删除文档，普通用户只能查看 |

企业级知识库必须有完整的鉴权体系，防止未授权访问敏感文档。

---

## 整体流程

```
用户注册 → 密码加密存储 → 用户登录 → 签发 JWT Token
    ↓
后续请求带 Token → 验证 Token → 获取用户信息
    ↓
检查权限（角色权限 + 文档权限 + 数据权限）
    ↓
允许 / 拒绝
```

### 鉴权层级

| 层级 | 说明 | 技术 |
|------|------|------|
| **接口级鉴权** | 哪些接口可以访问 | JWT + 角色检查 |
| **菜单级鉴权** | 哪些菜单可以看到 | 角色-菜单关联 |
| **按钮级鉴权** | 哪些按钮可以点击 | 角色-权限关联 |
| **文档级鉴权** | 哪些文档可以访问 | 文档所有者 + 共享 + 公开 |
| **数据级鉴权** | 哪些数据可以看到 | 部门隔离 + 角色过滤 |

### 1. 密码加密

```python
"""
security.py - 密码加密与验证
"""
from passlib.context import CryptContext
import secrets
import re

# 用 bcrypt 加密密码（自动加盐）
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")


def hash_password(password: str) -> str:
    """加密密码"""
    return pwd_context.hash(password)


def verify_password(plain_password: str, hashed_password: str) -> bool:
    """验证密码"""
    return pwd_context.verify(plain_password, hashed_password)


def generate_api_key() -> str:
    """生成 API Key（用于系统间调用）"""
    return "sk-" + secrets.token_hex(24)


def validate_password_strength(password: str) -> tuple:
    """
    校验密码强度

    Returns:
        tuple: (是否通过, 错误信息列表)
    """
    errors = []

    if len(password) < 8:
        errors.append("密码长度至少8位")
    if not re.search(r"[a-z]", password):
        errors.append("密码需包含小写字母")
    if not re.search(r"[A-Z]", password):
        errors.append("密码需包含大写字母")
    if not re.search(r"\d", password):
        errors.append("密码需包含数字")
    # if not re.search(r"[!@#$%^&*(),.?\":{}|<>]", password):
    #     errors.append("密码需包含特殊字符")

    return (len(errors) == 0, errors)
```

### 2. JWT Token 管理

```python
"""
jwt_utils.py - JWT Token 管理
"""
from datetime import datetime, timedelta
from jose import JWTError, jwt
from typing import Optional
import os

# 从环境变量读取，不要硬编码
SECRET_KEY = os.getenv("JWT_SECRET_KEY", "your-secret-key-change-in-production")
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30  # 访问令牌 30 分钟
REFRESH_TOKEN_EXPIRE_DAYS = 7      # 刷新令牌 7 天


def create_access_token(data: dict, expires_delta: Optional[timedelta] = None) -> str:
    """创建访问令牌"""
    to_encode = data.copy()
    expire = datetime.utcnow() + (expires_delta or timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES))
    to_encode.update({"exp": expire, "type": "access"})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)


def create_refresh_token(data: dict) -> str:
    """创建刷新令牌"""
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(days=REFRESH_TOKEN_EXPIRE_DAYS)
    to_encode.update({"exp": expire, "type": "refresh"})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)


def decode_token(token: str) -> Optional[dict]:
    """解码并验证 Token"""
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except JWTError:
        return None


def create_token_pair(user_id: int, username: str, role: str, department_id: int) -> dict:
    """创建 Token 对（access + refresh）"""
    access_token = create_access_token(data={
        "sub": str(user_id),
        "username": username,
        "role": role,
        "department_id": department_id,
    })
    refresh_token = create_refresh_token(data={"sub": str(user_id)})
    return {
        "access_token": access_token,
        "refresh_token": refresh_token,
        "token_type": "bearer",
    }
```

### 3. FastAPI 认证接口

```python
"""
auth_routes.py - FastAPI 认证接口
"""
from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from pydantic import BaseModel, EmailStr
from sqlalchemy.orm import Session
from datetime import datetime
from typing import Optional

from security import hash_password, verify_password, validate_password_strength, generate_api_key
from jwt_utils import create_token_pair, decode_token, create_access_token
from models import User, LoginLog
from database import get_db

router = APIRouter(prefix="/auth", tags=["认证"])

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="auth/login")


# ============ 数据模型 ============
class UserRegister(BaseModel):
    username: str
    email: EmailStr
    password: str
    nickname: Optional[str] = None


class TokenResponse(BaseModel):
    access_token: str
    refresh_token: str
    token_type: str = "bearer"


class UserInfo(BaseModel):
    id: int
    username: str
    email: str
    nickname: str
    role: str
    department_id: int
    avatar_url: Optional[str] = None


class RefreshTokenRequest(BaseModel):
    refresh_token: str


# ============ 依赖：获取当前用户 ============
async def get_current_user(
    token: str = Depends(oauth2_scheme),
    db: Session = Depends(get_db),
) -> UserInfo:
    """从 Token 中获取当前用户信息"""
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="无法验证凭据",
        headers={"WWW-Authenticate": "Bearer"},
    )

    payload = decode_token(token)
    if payload is None or payload.get("type") != "access":
        raise credentials_exception

    user_id = payload.get("sub")
    if user_id is None:
        raise credentials_exception

    # 从数据库查询用户
    user = db.query(User).filter(User.id == int(user_id)).first()
    if user is None or user.status != "active":
        raise credentials_exception

    return UserInfo(
        id=user.id,
        username=user.username,
        email=user.email,
        nickname=user.nickname,
        role=user.role,
        department_id=user.department_id,
        avatar_url=user.avatar_url,
    )


# 权限检查依赖
def require_role(required_role: str):
    """检查用户角色权限"""
    async def role_checker(current_user: UserInfo = Depends(get_current_user)):
        if current_user.role != required_role and current_user.role != "admin":
            raise HTTPException(status_code=403, detail="权限不足")
        return current_user
    return role_checker


# 多角色检查
def require_any_role(*roles: str):
    """检查用户是否拥有任一角色"""
    async def role_checker(current_user: UserInfo = Depends(get_current_user)):
        if current_user.role not in roles and current_user.role != "admin":
            raise HTTPException(status_code=403, detail="权限不足")
        return current_user
    return role_checker


# ============ 注册接口 ============
@router.post("/register", response_model=UserInfo)
async def register(user_data: UserRegister, db: Session = Depends(get_db)):
    """用户注册"""
    # 校验密码强度
    is_valid, errors = validate_password_strength(user_data.password)
    if not is_valid:
        raise HTTPException(status_code=400, detail="; ".join(errors))

    # 检查用户名/邮箱是否已存在
    existing = db.query(User).filter(
        (User.username == user_data.username) | (User.email == user_data.email)
    ).first()
    if existing:
        raise HTTPException(status_code=400, detail="用户名或邮箱已存在")

    # 创建用户
    hashed_pw = hash_password(user_data.password)
    new_user = User(
        username=user_data.username,
        email=user_data.email,
        password_hash=hashed_pw,
        nickname=user_data.nickname or user_data.username,
        role="user",
        status="active",
    )
    db.add(new_user)
    db.commit()
    db.refresh(new_user)

    return UserInfo(
        id=new_user.id,
        username=new_user.username,
        email=new_user.email,
        nickname=new_user.nickname,
        role=new_user.role,
        department_id=new_user.department_id or 0,
    )


# ============ 登录接口 ============
@router.post("/login", response_model=TokenResponse)
async def login(
    form_data: OAuth2PasswordRequestForm = Depends(),
    db: Session = Depends(get_db),
):
    """用户登录（OAuth2 格式）"""
    # 从数据库查询用户
    user = db.query(User).filter(User.username == form_data.username).first()

    # 记录登录日志
    login_log = LoginLog(
        user_id=user.id if user else None,
        username=form_data.username,
        ip_address="127.0.0.1",  # 实际从 request 获取
        user_agent="",
        status="failed",
    )

    if not user or not verify_password(form_data.password, user.password_hash):
        login_log.error_message = "用户名或密码错误"
        db.add(login_log)
        db.commit()
        raise HTTPException(status_code=401, detail="用户名或密码错误")

    if user.status != "active":
        login_log.error_message = "账号已被禁用"
        db.add(login_log)
        db.commit()
        raise HTTPException(status_code=403, detail="账号已被禁用")

    # 签发 Token
    tokens = create_token_pair(user.id, user.username, user.role, user.department_id or 0)

    # 更新登录时间
    user.last_login_at = datetime.now()

    # 记录登录日志
    login_log.status = "success"
    login_log.user_id = user.id

    db.add(login_log)
    db.commit()

    return tokens


# ============ 刷新 Token ============
@router.post("/refresh", response_model=TokenResponse)
async def refresh_token(
    request: RefreshTokenRequest,
    db: Session = Depends(get_db),
):
    """刷新访问令牌"""
    payload = decode_token(request.refresh_token)
    if payload is None or payload.get("type") != "refresh":
        raise HTTPException(status_code=401, detail="刷新令牌无效")

    user_id = payload.get("sub")
    user = db.query(User).filter(User.id == int(user_id)).first()
    if not user or user.status != "active":
        raise HTTPException(status_code=401, detail="用户不存在或已禁用")

    # 签发新的 Token 对（刷新令牌轮换）
    tokens = create_token_pair(user.id, user.username, user.role, user.department_id or 0)
    return tokens


# ============ 登出接口 ============
@router.post("/logout")
async def logout(current_user: UserInfo = Depends(get_current_user)):

    # 实际项目中可以将 Token 加入 Redis 黑名单

@router.get("/me", response_model=UserInfo)
async def get_me(current_user: UserInfo = Depends(get_current_user)):
    """获取当前用户信息"""
    return current_user


# ============ 修改密码 ============
class ChangePasswordRequest(BaseModel):
    old_password: str
    new_password: str


@router.post("/change-password")
async def change_password(
    request: ChangePasswordRequest,
    current_user: UserInfo = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    """修改密码"""
    user = db.query(User).filter(User.id == current_user.id).first()

    # 验证旧密码
    if not verify_password(request.old_password, user.password_hash):
        raise HTTPException(status_code=400, detail="旧密码错误")

    # 校验新密码强度
    is_valid, errors = validate_password_strength(request.new_password)
    if not is_valid:
        raise HTTPException(status_code=400, detail="; ".join(errors))

    # 更新密码
    user.password_hash = hash_password(request.new_password)
    db.commit()

    return {"message": "密码修改成功"}
```

```python
"""
rbac.py - 基于角色的访问控制（RBAC）
"""
from fastapi import Depends, HTTPException
from auth_routes import get_current_user, UserInfo
from sqlalchemy.orm import Session
from models import Role, Permission, RolePermission, UserRole
from database import get_db
from typing import Set


# 权限常量
PERMISSIONS = {
    # 文档管理
    "document:create": "创建文档",
    "document:read": "查看文档",
    "document:update": "编辑文档",
    "document:delete": "删除文档",
    "document:publish": "发布文档",
    "document:review": "审核文档",
    # 用户管理
    "user:create": "创建用户",
    "user:read": "查看用户",
    "user:update": "编辑用户",
    "user:delete": "删除用户",
    # 系统管理
    "system:config": "系统配置",
    "system:log": "查看日志",
}


def get_user_permissions(user_id: int, db: Session) -> Set[str]:
    """获取用户的所有权限（通过角色关联）"""
    # 查询用户角色
    user_roles = db.query(UserRole).filter(UserRole.user_id == user_id).all()
    role_ids = [ur.role_id for ur in user_roles]

    if not role_ids:
        return set()

    # 查询角色权限
    role_permissions = db.query(RolePermission).filter(
        RolePermission.role_id.in_(role_ids)
    ).all()
    permission_ids = [rp.permission_id for rp in role_permissions]

    if not permission_ids:
        return set()

    # 查询权限编码
    permissions = db.query(Permission).filter(Permission.id.in_(permission_ids)).all()
    return {p.code for p in permissions}


def require_permission(permission_code: str):
    """
    权限检查依赖（细粒度权限）

    用法：@router.get("/documents", dependencies=[Depends(require_permission("document:read"))])
    """
    async def permission_checker(
        current_user: UserInfo = Depends(get_current_user),
        db: Session = Depends(get_db),
    ):
        # 管理员拥有所有权限
        if current_user.role == "admin":
            return current_user

        # 获取用户权限
        permissions = get_user_permissions(current_user.id, db)

        if permission_code not in permissions:
            raise HTTPException(status_code=403, detail=f"缺少权限: {permission_code}")

        return current_user

    return permission_checker
```

### 5. 文档级权限控制

```python
"""
document_permissions.py - 文档级权限控制
"""
from fastapi import Depends, HTTPException
from auth_routes import get_current_user, UserInfo
from sqlalchemy.orm import Session
from models import Document, DocumentPermission
from database import get_db
from enum import IntEnum


class DocumentPermissionLevel(IntEnum):
    """文档权限级别"""
    NONE = 0       # 无权限
    READ = 1       # 只读
    WRITE = 2      # 编辑
    OWNER = 3      # 所有者


def get_document_permission(
    user_id: int,
    doc_id: int,
    db: Session,
) -> DocumentPermissionLevel:
    """
    获取用户对文档的权限级别

    权限优先级：所有者 > 共享权限 > 公开 > 部门权限
    """
    doc = db.query(Document).filter(Document.id == doc_id).first()
    if not doc:
        return DocumentPermissionLevel.NONE

    # 1. 所有者
    if doc.author_id == user_id:
        return DocumentPermissionLevel.OWNER

    # 2. 共享权限
    shared = db.query(DocumentPermission).filter(
        DocumentPermission.document_id == doc_id,
        DocumentPermission.user_id == user_id,
    ).first()
    if shared:
        return DocumentPermissionLevel(shared.permission_level)

    # 3. 公开文档
    if doc.is_public:
        return DocumentPermissionLevel.READ

    # 4. 部门权限（同部门可查看）
    user = db.query(User).filter(User.id == user_id).first()
    if user and user.department_id and user.department_id == doc.department_id:
        return DocumentPermissionLevel.READ

    return DocumentPermissionLevel.NONE


def require_doc_read(doc_id: int):
    """文档读权限检查依赖"""
    async def checker(
        current_user: UserInfo = Depends(get_current_user),
        db: Session = Depends(get_db),
    ):
        permission = get_document_permission(current_user.id, doc_id, db)
        if permission < DocumentPermissionLevel.READ:
            raise HTTPException(status_code=403, detail="无权访问该文档")
        return current_user
    return checker


def require_doc_write(doc_id: int):
    """文档写权限检查依赖"""
    async def checker(
        current_user: UserInfo = Depends(get_current_user),
        db: Session = Depends(get_db),
    ):
        permission = get_document_permission(current_user.id, doc_id, db)
        if permission < DocumentPermissionLevel.WRITE:
            raise HTTPException(status_code=403, detail="无权编辑该文档")
        return current_user
    return checker


def require_doc_owner(doc_id: int):
    """文档所有者检查依赖"""
    async def checker(
        current_user: UserInfo = Depends(get_current_user),
        db: Session = Depends(get_db),
    ):
        permission = get_document_permission(current_user.id, doc_id, db)
        if permission < DocumentPermissionLevel.OWNER:
            raise HTTPException(status_code=403, detail="只有文档所有者可以执行此操作")
        return current_user
    return checker
```

### 6. 数据权限隔离

```python
"""
data_permissions.py - 数据权限隔离
"""
from auth_routes import get_current_user, UserInfo
from sqlalchemy.orm import Session
from models import User, Document
from database import get_db
from fastapi import Depends
from typing import List


def get_visible_document_ids(
    current_user: UserInfo,
    db: Session,
) -> List[int]:
    """
    获取用户可见的文档ID列表（用于检索时过滤）

    可见条件：
    1. 自己创建的文档
    2. 公开文档
    3. 共享给自己的文档
    4. 同部门的文档（如果开启了部门可见）
    5. 管理员可见所有
    """
    # 管理员可见所有
    if current_user.role == "admin":
        docs = db.query(Document.id).all()
        return [d.id for d in docs]

    # 普通用户
    visible_ids = set()

    # 1. 自己创建的
    my_docs = db.query(Document.id).filter(Document.author_id == current_user.id).all()
    visible_ids.update(d.id for d in my_docs)

    # 2. 公开文档
    public_docs = db.query(Document.id).filter(Document.is_public == True).all()
    visible_ids.update(d.id for d in public_docs)

    # 3. 共享给自己的
    from models import DocumentPermission
    shared = db.query(DocumentPermission.document_id).filter(
        DocumentPermission.user_id == current_user.id,
        DocumentPermission.permission_level >= 1,
    ).all()
    visible_ids.update(d.document_id for d in shared)

    # 4. 同部门文档（可选）
    if current_user.department_id:
        dept_docs = db.query(Document.id).filter(
            Document.department_id == current_user.department_id,
            Document.is_dept_public == True,
        ).all()
        visible_ids.update(d.id for d in dept_docs)

    return list(visible_ids)


def filter_documents_by_permission(
    query,
    current_user: UserInfo,
    db: Session,
):
    """
    在 SQLAlchemy 查询中加入权限过滤

    用法：
    query = db.query(Document)
    query = filter_documents_by_permission(query, current_user, db)
    docs = query.all()
    """
    # 管理员不过滤
    if current_user.role == "admin":
        return query

    visible_ids = get_visible_document_ids(current_user, db)
    return query.filter(Document.id.in_(visible_ids))
```

```python
"""
api_key_auth.py - API Key 认证（系统间调用）
"""
from fastapi import Depends, HTTPException, Security
from fastapi.security import APIKeyHeader
from sqlalchemy.orm import Session
from models import APIKey
from database import get_db

api_key_header = APIKeyHeader(name="X-API-Key", auto_error=False)


async def get_api_key_user(
    api_key: str = Security(api_key_header),
    db: Session = Depends(get_db),
):
    """通过 API Key 认证（系统间调用）"""
    if not api_key:
        raise HTTPException(status_code=401, detail="缺少 API Key")

    key_record = db.query(APIKey).filter(
        APIKey.key == api_key,
        APIKey.is_active == True,
    ).first()

    if not key_record:
        raise HTTPException(status_code=401, detail="API Key 无效")

    # 检查是否过期
    if key_record.expires_at and key_record.expires_at < datetime.now():
        raise HTTPException(status_code=401, detail="API Key 已过期")

    return key_record
```

## 安全最佳实践

### 1. 密码安全

| 实践 | 说明 |
|------|------|
| **使用 bcrypt/argon2** | 不要用 MD5/SHA1，bcrypt 自动加盐且计算慢 |
| **密码强度校验** | 最少8位，含大小写+数字，可选特殊字符 |
| **登录失败次数限制** | 连续失败5次锁定账号15分钟，防暴力破解 |
| **密码定期更换** | 建议90天更换一次，系统提醒 |
| **密码历史检查** | 不能使用最近5次使用过的密码 |

### 2. Token 安全

| 实践 | 说明 |
|------|------|
| **Access Token 短期** | 15-30分钟，减少泄露风险 |
| **Refresh Token 长期** | 7天，用于刷新 Access Token |
| **Refresh Token 轮换** | 每次刷新都签发新的 Refresh Token，旧的失效 |
| **Token 黑名单** | 登出时将 Token 加入 Redis 黑名单，防止复用 |
| **HTTPS 传输** | 所有请求必须走 HTTPS，防止 Token 被截获 |

### 3. 接口安全

| 实践 | 说明 |
|------|------|
| **速率限制** | 登录接口限制每分钟10次，防暴力破解 |
| **CORS 配置** | 只允许可信域名访问 |
| **输入校验** | 所有输入参数都要校验，防 SQL 注入、XSS |
| **敏感信息脱敏** | 日志中不记录密码、Token 等敏感信息 |
| **审计日志** | 记录所有敏感操作（登录、修改密码、删除文档） |

### 4. 数据安全

| 实践 | 说明 |
|------|------|
| **数据权限隔离** | 用户只能看到有权限的数据，部门间数据隔离 |
| **敏感数据加密** | 手机号、身份证等敏感字段加密存储 |
| **数据备份** | 定期备份数据库，防止数据丢失 |
| **数据销毁** | 用户注销时按法规要求销毁或匿名化数据 |

## 学习要点

1. **认证和鉴权是两个不同的概念**：认证是"你是谁"，鉴权是"你能做什么"
2. **JWT 是无状态认证的主流方案**：Access Token 短期 + Refresh Token 长期，兼顾安全和体验
3. **密码必须用 bcrypt/argon2 加密**：不要用 MD5/SHA1，bcrypt 自动加盐且计算慢
4. **RBAC 是企业级权限管理的标准模型**：用户-角色-权限三级关联，灵活可扩展
5. **文档级权限是知识库的核心**：所有者 > 共享权限 > 公开 > 部门权限
6. **数据权限隔离是企业级必备**：检索时必须过滤用户无权访问的文档
7. **API Key 用于系统间调用**：和用户认证分开，有独立的权限和过期时间
8. **安全最佳实践不能忽视**：密码强度、登录限制、Token 轮换、速率限制、审计日志
9. **FastAPI 的依赖注入让鉴权很优雅**：用 Depends 统一处理认证和权限检查
10. **多层级鉴权是企业级的标配**：接口级、菜单级、按钮级、文档级、数据级

## 扩展方向

- 学习 OAuth2.0 第三方登录（微信、GitHub、Google、飞书）
- 探索 SSO 单点登录（SAML、OIDC、CAS）
- 学习 MFA 多因素认证（短信验证码、TOTP、硬件密钥、生物识别）
- 探索 ABAC 基于属性的访问控制（更灵活的权限模型）
- 学习零信任架构（Zero Trust、持续验证、最小权限）
- 探索密码less 认证（Passkey、WebAuthn、FIDO2）
- 学习 API 网关鉴权（Kong、APISIX、Nginx、JWT 校验）
- 探索微服务鉴权（服务间认证、mTLS、Service Mesh）
- 学习安全审计（操作日志、异常检测、合规要求、等保2.0）
- 探索数据隐私（GDPR、个人信息保护法、数据脱敏、数据分类分级）
