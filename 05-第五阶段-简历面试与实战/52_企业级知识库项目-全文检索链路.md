## 为什么需要全文检索？

纯向量检索（RAG）擅长语义匹配，但有短板：

| 短板 | 说明 | 示例 |
|------|------|------|
| **精确关键词搜索差** | 产品型号、人名、错误码等专有名词 | "iPhone 15 Pro Max"、"Error 500" |
| **无法做复杂条件过滤** | 时间范围、文档类型、作者、分类 | "2024年的PDF技术文档" |
| **同义词/缩写可能漏召回** | "AI"和"人工智能"可能被视为不同 | "AI" ≠ "人工智能" |
| **无法做高亮显示** | 不能展示命中关键词的位置 | 前端无法高亮匹配词 |

**全文检索（ElasticSearch）** 补全这些能力，和向量检索结合形成**混合检索**。

---

## 检索链路架构

```
用户查询
    ↓
Query 预处理（分词、纠错、扩展、改写）
    ↓
┌─────────────┐    ┌─────────────┐
│  向量检索     │    │  全文检索     │
│  (PGVector)  │    │  (ES)        │
└──────┬──────┘    └──────┬──────┘
       │                    │
       └────────┬───────────┘
                ↓
          合并去重（Reciprocal Rank Fusion）
                ↓
          Reranker 重排（BGE-Reranker）
                ↓
          Top-K 结果 → 拼接 Prompt → 大模型生成
```

### 各阶段职责

| 阶段 | 技术 | 职责 | 输出 |
|------|------|------|------|
| **Query 预处理** | LLM/规则 | 分词、纠错、扩展、改写 | 优化后的查询 |
| **向量检索** | PGVector | 语义相似度检索 | Top-20 向量结果 |
| **全文检索** | ElasticSearch | 关键词匹配 + 过滤 | Top-20 全文结果 |
| **结果融合** | RRF | 合并多路召回结果 | 去重后的 Top-20 |
| **Reranker 重排** | BGE-Reranker | 交叉编码器精排 | Top-5 最终结果 |
| **RAG 生成** | LLM | 拼接上下文 + 生成回答 | 最终答案 + 来源 |

### 2. 文档索引写入

```python
"""
es_indexer.py - 文档索引写入
"""
from elasticsearch import Elasticsearch
from elasticsearch.helpers import bulk
from datetime import datetime

es = Elasticsearch("http://localhost:9200")
INDEX_NAME = "knowledge_base"


def index_chunks(doc_id, chunks, metadata):
    """
    批量索引文档分块

    Args:
        doc_id: 文档ID
        chunks: LangChain Document 列表
        metadata: 文档元数据

    Returns:
        int: 成功索引数量
    """
    actions = []
    for i, chunk in enumerate(chunks):
        actions.append({
            "_index": INDEX_NAME,
            "_id": f"{doc_id}_{i}",
            "_source": {
                "doc_id": doc_id,
                "chunk_id": f"{doc_id}_{i}",
                "content": chunk.page_content,
                "title": metadata.get("title", ""),
                "doc_type": metadata.get("file_type", ""),
                "category": metadata.get("category", ""),
                "author": metadata.get("author", ""),
                "department": metadata.get("department", ""),
                "page": chunk.metadata.get("page", 0),
                "tags": metadata.get("tags", []),
                "is_public": metadata.get("is_public", False),
                "word_count": len(chunk.page_content),
                "created_at": metadata.get("created_at", datetime.now().isoformat()),
                "updated_at": datetime.now().isoformat(),
            }
        })

    # 批量写入
    success, failed = bulk(es, actions, raise_on_error=False)

    if failed:
        print(f"⚠️  索引失败: {len(failed)} 条")
        for f in failed[:5]:
            print(f"  - {f}")

    print(f"✅ 索引完成: 成功 {success}, 失败 {len(failed)}")
    return success


def delete_document(doc_id):
    """删除文档的所有分块索引"""
    query = {
        "query": {
            "term": {"doc_id": doc_id}
        }
    }
    result = es.delete_by_query(index=INDEX_NAME, body=query)
    print(f"🗑️  删除文档 {doc_id}: {result['deleted']} 条")
    return result["deleted"]


def update_document(doc_id, chunks, metadata):
    """更新文档索引（先删后写）"""
    delete_document(doc_id)
    return index_chunks(doc_id, chunks, metadata)
```

### 3. 全文检索

```python
"""
es_search.py - 全文检索
"""
from elasticsearch import Elasticsearch

es = Elasticsearch("http://localhost:9200")
INDEX_NAME = "knowledge_base"


def keyword_search(query, filters=None, top_k=10):
    """
    全文检索 + 条件过滤

    Args:
        query: 查询文本
        filters: 过滤条件，如 {"doc_type": "pdf", "category": "技术文档"}
        top_k: 返回数量

    Returns:
        list: 检索结果列表
    """
    # 多字段匹配：title 权重 3 倍，content 权重 1 倍
    must_clauses = [
        {
            "multi_match": {
                "query": query,
                "fields": ["title^3", "content"],
                "type": "best_fields",
                "tie_breaker": 0.3,
            }
        }
    ]

    # 过滤条件
    filter_clauses = []
    if filters:
        for key, value in filters.items():
            if isinstance(value, list):
                filter_clauses.append({"terms": {key: value}})
            elif isinstance(value, dict) and "gte" in value:
                filter_clauses.append({"range": {key: value}})
            else:
                filter_clauses.append({"term": {key: value}})

    search_body = {
        "query": {
            "bool": {
                "must": must_clauses,
                "filter": filter_clauses,
            }
        },
        "highlight": {
            "fields": {
                "content": {
                    "pre_tags": ["<em>"],
                    "post_tags": ["</em>"],
                    "fragment_size": 150,
                    "number_of_fragments": 1,
                },
                "title": {
                    "pre_tags": ["<em>"],
                    "post_tags": ["</em>"],
                },
            }
        },
        "size": top_k,
        "_source": ["doc_id", "chunk_id", "content", "title", "doc_type", "page", "tags"],
    }

    result = es.search(index=INDEX_NAME, body=search_body)

    chunks = []
    for hit in result["hits"]["hits"]:
        source = hit["_source"]
        highlight = hit.get("highlight", {})
        chunks.append({
            "chunk_id": source["chunk_id"],
            "doc_id": source["doc_id"],
            "content": source["content"],
            "title": source.get("title", ""),
            "doc_type": source.get("doc_type", ""),
            "page": source.get("page", 0),
            "score": hit["_score"],
            "highlight": highlight.get("content", [source["content"][:150]])[0],
            "source": "keyword",
        })

    return chunks


def advanced_search(query, filters=None, date_range=None, top_k=10):
    """
    高级检索：支持时间范围、布尔查询、短语匹配

    Args:
        query: 查询文本
        filters: 过滤条件
        date_range: 时间范围，如 {"gte": "2024-01-01", "lte": "2024-12-31"}
        top_k: 返回数量
    """
    must_clauses = [
        {
            "multi_match": {
                "query": query,
                "fields": ["title^3", "content"],
                "type": "best_fields",
            }
        }
    ]

    filter_clauses = []

    # 字段过滤
    if filters:
        for key, value in filters.items():
            filter_clauses.append({"term": {key: value}})

    # 时间范围过滤
    if date_range:
        filter_clauses.append({"range": {"created_at": date_range}})

    search_body = {
        "query": {
            "bool": {
                "must": must_clauses,
                "filter": filter_clauses,
            }
        },
        "highlight": {
            "fields": {
                "content": {"pre_tags": ["<em>"], "post_tags": ["</em>"]},
            }
        },
        "size": top_k,
        "sort": [{"_score": "desc"}],
    }

    result = es.search(index=INDEX_NAME, body=search_body)
    return [hit["_source"] for hit in result["hits"]["hits"]]
```

### 4. 混合检索（向量 + 全文）

```python
"""
hybrid_search.py - 混合检索（向量 + 全文）
"""
from es_search import keyword_search
from langchain_community.vectorstores import PGVector
from langchain_openai import OpenAIEmbeddings

# 初始化
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vectorstore = PGVector(
    collection_name="knowledge_base",
    connection_string="postgresql+psycopg2://user:password@localhost:5432/kb",
    embedding_function=embeddings,
)


def vector_search(query, top_k=10, filters=None):
    """
    向量检索

    Args:
        query: 查询文本
        top_k: 返回数量
        filters: 元数据过滤条件

    Returns:
        list: 检索结果列表
    """
    # PGVector 的过滤条件
    search_kwargs = {"k": top_k}
    if filters:
        search_kwargs["filter"] = filters

    results = vectorstore.similarity_search_with_score(query, **search_kwargs)

    chunks = []
    for doc, score in results:
        chunks.append({
            "chunk_id": doc.metadata.get("chunk_id", ""),
            "doc_id": doc.metadata.get("doc_id", ""),
            "content": doc.page_content,
            "title": doc.metadata.get("title", ""),
            "score": float(score),
            "source": "vector",
        })

    return chunks


def reciprocal_rank_fusion(results_list, k=60):
    """
    RRF 融合算法：把多个检索结果的排名合并

    score = Σ 1 / (k + rank_i)

    Args:
        results_list: 多个检索结果列表
        k: 平滑参数（默认60）

    Returns:
        list: 融合后的结果列表
    """
    fused_scores = {}

    for results in results_list:
        for rank, item in enumerate(results):
            cid = item["chunk_id"]
            if cid not in fused_scores:
                fused_scores[cid] = {"item": item, "score": 0, "sources": []}
            fused_scores[cid]["score"] += 1 / (k + rank + 1)
            fused_scores[cid]["sources"].append(item["source"])

    # 按融合分数排序
    sorted_results = sorted(fused_scores.values(), key=lambda x: x["score"], reverse=True)

    # 添加融合分数和来源
    for r in sorted_results:
        r["item"]["fused_score"] = r["score"]
        r["item"]["sources"] = r["sources"]

    return [r["item"] for r in sorted_results]


def rerank_with_cross_encoder(query, results, top_k=5):
    """
    使用交叉编码器（Reranker）重排

    Args:
        query: 查询文本
        results: 待重排结果
        top_k: 返回数量

    Returns:
        list: 重排后的结果
    """
    try:
        from sentence_transformers import CrossEncoder

        # 加载 Reranker 模型
        reranker = CrossEncoder('BAAI/bge-reranker-base')

        # 构建 (query, content) 对
        pairs = [[query, item['content']] for item in results]

        # 预测相关性分数
        scores = reranker.predict(pairs)

        # 添加重排分数
        for item, score in zip(results, scores):
            item['rerank_score'] = float(score)

        # 按重排分数排序
        results.sort(key=lambda x: x.get('rerank_score', 0), reverse=True)

        return results[:top_k]

    except ImportError:
        print("⚠️  sentence-transformers 未安装，跳过 Reranker")
        return results[:top_k]


def hybrid_search(query, filters=None, top_k=5, use_reranker=True):
    """
    混合检索：向量 + 全文，RRF 融合，Reranker 重排

    Args:
        query: 查询文本
        filters: 过滤条件
        top_k: 最终返回数量
        use_reranker: 是否使用 Reranker 重排

    Returns:
        list: 最终检索结果
    """
    # 1. 多路召回（各取 Top-20）
    vec_results = vector_search(query, top_k=20, filters=filters)
    kw_results = keyword_search(query, filters=filters, top_k=20)

    print(f"🔍 向量检索: {len(vec_results)} 条")
    print(f"🔍 全文检索: {len(kw_results)} 条")

    # 2. RRF 融合
    merged = reciprocal_rank_fusion([vec_results, kw_results])
    print(f"🔗 RRF 融合后: {len(merged)} 条")

    # 3. Reranker 重排（可选，提升准确率）
    if use_reranker and len(merged) > top_k:
        merged = rerank_with_cross_encoder(query, merged, top_k=top_k)
        print(f"🎯 Reranker 重排后: {len(merged)} 条")
    else:
        merged = merged[:top_k]

    return merged
```

### 5. Query 预处理（完整实现）

```python
"""
query_preprocessor.py - 查询预处理
"""
from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)


def preprocess_query(query):
    """
    查询预处理：纠错、扩展、同义词替换、改写

    Args:
        query: 原始查询

    Returns:
        dict: 预处理结果
    """
    # 1. 拼写纠错（用大模型）
    corrected = correct_spelling(query)

    # 2. 同义词扩展
    expanded = expand_synonyms(corrected)

    # 3. Query 改写（口语化 → 检索友好）
    rewritten = rewrite_query(corrected)

    # 4. 生成多个查询（多路召回）
    queries = generate_multiple_queries(corrected)

    return {
        "original": query,
        "corrected": corrected,
        "expanded": expanded,
        "rewritten": rewritten,
        "multiple_queries": queries,
    }


def correct_spelling(query):
    """拼写纠错"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", "你是一个拼写纠错助手。如果用户输入有拼写错误，请纠正；如果没有错误，原样返回。只返回纠正后的文本，不要解释。"),
        ("human", "{query}"),
    ])
    chain = prompt | llm
    return chain.invoke({"query": query}).content.strip()


def expand_synonyms(query):
    """同义词扩展"""
    # 简单的同义词词典
    synonyms = {
        "AI": "人工智能",
        "LLM": "大语言模型",
        "RAG": "检索增强生成",
        "Agent": "智能体",
        "KB": "知识库",
    }

    expanded = query
    for abbr, full in synonyms.items():
        if abbr in expanded and full not in expanded:
            expanded = expanded.replace(abbr, f"{abbr} {full}")

    return expanded


def rewrite_query(query):
    """
    Query 改写：把口语化问题改写成检索友好的查询

    示例：
    "怎么用Python连接数据库？" → "Python 数据库连接 教程 示例代码"
    """
    prompt = ChatPromptTemplate.from_messages([
        ("system", """你是一个查询改写助手。把用户的口语化问题改写成适合搜索引擎的关键词查询。
要求：
1. 提取核心关键词
2. 去掉疑问词和语气词
3. 保留专业术语
4. 用空格分隔关键词
5. 只返回改写后的查询，不要解释"""),
        ("human", "{query}"),
    ])
    chain = prompt | llm
    return chain.invoke({"query": query}).content.strip()


def generate_multiple_queries(query, n=3):
    """
    生成多个查询（用于多路召回，提升召回率）

    示例：
    "Python连接数据库" → ["Python 数据库连接", "Python SQLAlchemy 教程", "Python 数据库 ORM"]
    """
    prompt = ChatPromptTemplate.from_messages([
        ("system", f"""你是一个查询扩展助手。为用户的查询生成 {n} 个不同的检索查询，用于多路召回。
要求：
1. 每个查询从不同角度表达
2. 可以包含同义词、相关术语
3. 每个查询用换行分隔
4. 只返回查询列表，不要解释"""),
        ("human", "{query}"),
    ])
    chain = prompt | llm
    result = chain.invoke({"query": query}).content.strip()
    queries = [q.strip() for q in result.split("\n") if q.strip()]
    return queries[:n]


# 使用示例
if __name__ == "__main__":
    query = "怎么用Python连接数据库？"
    result = preprocess_query(query)
    print(f"原始查询: {result['original']}")
    print(f"纠错后: {result['corrected']}")
    print(f"扩展后: {result['expanded']}")
    print(f"改写后: {result['rewritten']}")
    print(f"多路查询: {result['multiple_queries']}")
```

```python
"""

"""

    ("system", """你是一个专业的知识库问答助手。根据以下参考资料回答用户问题。

参考资料：
{context}

回答要求：

def ask_question(question, filters=None, use_reranker=True, stream=False):
    """
    RAG 问答

    Args:
        question: 用户问题
        filters: 过滤条件
        use_reranker: 是否使用 Reranker
        stream: 是否流式输出

    Returns:
        dict: 回答结果
    """
    # 1. Query 预处理
    preprocessed = preprocess_query(question)
    search_query = preprocessed["rewritten"]

    # 2. 混合检索
    chunks = hybrid_search(search_query, filters=filters, top_k=5, use_reranker=use_reranker)

    # 3. 拼接上下文
    context = ""
    sources = []
    for i, chunk in enumerate(chunks, 1):
        context += f"[{i}] (文档: {chunk.get('title', '未知')}, 页码: {chunk.get('page', '?')}) {chunk['content']}\n\n"
        sources.append({
            "index": i,
            "title": chunk.get('title', ''),
            "doc_id": chunk.get('doc_id', ''),
            "page": chunk.get('page', 0),
            "score": chunk.get('score', 0),
            "rerank_score": chunk.get('rerank_score', 0),
            "sources": chunk.get('sources', []),
        })

    # 4. 大模型生成
    chain = RAG_PROMPT | llm | StrOutputParser()

    if stream:
        # 流式输出
        def generate():
            for chunk in chain.stream({"context": context, "question": question}):
                yield chunk
        return {"answer_stream": generate(), "sources": sources}
    else:
        # 一次性输出
        answer = chain.invoke({"context": context, "question": question})
        return {
            "answer": answer,
            "sources": sources,
            "query": question,
            "search_query": search_query,
        }


# 使用示例
if __name__ == "__main__":
    result = ask_question("什么是混合检索？")
    print(f"回答: {result['answer']}")
    print(f"\n来源:")
    for s in result['sources']:
        print(f"  [{s['index']}] {s['title']} (相似度: {s['score']:.4f})")
```

## A/B 测试与效果评估

```python
"""
evaluation.py - 检索效果评估
"""
import json
from hybrid_search import hybrid_search


def evaluate_retrieval(test_cases, top_k=5):
    """
    评估检索效果

    Args:
        test_cases: 测试用例列表，每个包含 query 和 relevant_doc_ids
        top_k: 返回数量

    Returns:
        dict: 评估指标
    """
    total_recall = 0
    total_precision = 0
    total_mrr = 0

    for case in test_cases:
        query = case["query"]
        relevant_ids = set(case["relevant_doc_ids"])

        # 检索
        results = hybrid_search(query, top_k=top_k)
        result_ids = [r["doc_id"] for r in results]

        # 计算指标
        hits = len(set(result_ids) & relevant_ids)

        # Recall: 相关文档被检索到的比例
        recall = hits / len(relevant_ids) if relevant_ids else 0
        total_recall += recall

        # Precision: 检索结果中相关文档的比例
        precision = hits / len(result_ids) if result_ids else 0
        total_precision += precision

        # MRR: 第一个相关文档的排名倒数
        mrr = 0
        for rank, doc_id in enumerate(result_ids, 1):
            if doc_id in relevant_ids:
                mrr = 1 / rank
                break
        total_mrr += mrr

    n = len(test_cases)
    return {
        "recall@5": total_recall / n,
        "precision@5": total_precision / n,
        "mrr": total_mrr / n,
        "test_cases": n,
    }


# 测试用例
test_cases = [
    {
        "query": "什么是混合检索？",
        "relevant_doc_ids": ["doc_001", "doc_002"],
    },
    {
        "query": "如何用Python连接PostgreSQL？",
        "relevant_doc_ids": ["doc_010", "doc_011"],
    },
]

# 评估
metrics = evaluate_retrieval(test_cases)
print(json.dumps(metrics, indent=2, ensure_ascii=False))
```

## 学习要点

1. **企业级知识库必须用混合检索**：向量（语义）+ 全文（关键词），互补短板，提升召回率和准确率
2. **ES 索引用 ik_max_word 索引、ik_smart 搜索**：中文分词效果好，细粒度索引、粗粒度搜索
3. **RRF（Reciprocal Rank Fusion）是简单有效的结果融合算法**：不需要归一化分数，直接用排名融合
4. **Reranker 重排是准确率提升的关键**：交叉编码器精排，推荐 BGE-Reranker，能显著提升 Top-K 准确率
5. **全文检索支持复杂过滤**：类型、分类、时间、部门、公开状态，这是向量检索没有的
6. **Query 预处理能显著提升检索效果**：纠错、扩展、改写、多路查询，把口语化问题转成检索友好的查询
7. **高亮显示提升用户体验**：ES highlight 返回命中关键词的片段，前端可以展示匹配位置
8. **同义词词典提升召回率**：自定义同义词，把缩写和全称视为同义词
9. **性能优化是生产必备**：分片、字段裁剪、分页优化、缓存、批量索引
10. **A/B 测试和效果评估**：用 Recall@K、Precision@K、MRR 等指标量化检索效果，持续优化
