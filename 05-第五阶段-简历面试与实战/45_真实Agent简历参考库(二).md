## 第三份：父子分块知识库 RAG

![简历](../IMG/2026-07-25_真实Agent简历参考库（二）/8_公众号_Yi昭.webp)

### 项目亮点

| 技术点 | 说明 |
|--------|------|
| **混合检索** | 向量 + 关键词混合检索（标配） |
| **父子分块** | 按大章节拆分父块，章节内部再分小的子块，子块通过元数据关联父块 |
| **子块向量化** | 子块做向量化，携带父块元数据，存入 Milvus |
| **父块溯源** | 用户问题检索出子块，通过父块 id 检索 PostgreSQL 里的父块原文 |
| **意图识别微调** | 微调了一个大模型来做意图识别 |

![父子分块架构](../IMG/2026-07-25_真实Agent简历参考库（二）/9_公众号_Yi昭.webp)

**父子分块说明**：一般直接用 LLM + Few-Shot 少量案例做意图识别就足够了，复杂一点可以微调模型来做。

## 第五份：儿科疾病多模态知识库（GraphRAG）

![简历第一页](../IMG/2026-07-25_真实Agent简历参考库（二）/11_公众号_Yi昭.webp)

![简历第二页](../IMG/2026-07-25_真实Agent简历参考库（二）/12_公众号_Yi昭.webp)

### 项目亮点

| 技术点 | 说明 |
|--------|------|
| **GraphRAG** | 语义 + 关键词 + 知识图谱的混合检索 |
| **跨模态检索** | 文本、图片用多模态嵌入模型统一映射为向量，做图文跨模态检索 |
| **图搜图** | 直接用多模态嵌入模型做向量化，可以图搜图 |
| **短期记忆** | 滑动窗口 + 摘要 |
| **长期记忆** | 语义 + 全文检索 |
| **RAG 评估** | 做了 RAG 评估体系 |

![跨模态检索 vs OCR检索](../IMG/2026-07-25_真实Agent简历参考库（二）/13_公众号_Yi昭.webp)

**跨模态实现说明**：如果是图片 OCR 提取文字再走文本检索，会丢失图片的布局信息，只是根据文本来检索。如果图片里没有文字呢？所以直接用多模态嵌入模型来做会更靠谱一些。

![多模态嵌入模型原理](../IMG/2026-07-25_真实Agent简历参考库（二）/14_公众号_Yi昭.webp)

![阿里多模态嵌入模型](../IMG/2026-07-25_真实Agent简历参考库（二）/15_公众号_Yi昭.webp)

天然支持图搜图、文搜图、视频搜视频等跨模态检索。

整体项目就是混合检索 + 知识图谱的架构：

![混合检索+知识图谱架构](../IMG/2026-07-25_真实Agent简历参考库（二）/16_公众号_Yi昭.webp)

## 学习要点

1. **技术栈高度趋同**：看得简历多了会发现各种 Agent 技术方案都差不多，自然就知道学习重点和简历怎么写
2. **混合检索是标配**：向量 + 关键词混合检索几乎出现在每一份知识库简历中，必须掌握
3. **Agentic RAG 是加分项**：让 LLM 参与检索决策（查询改写、质量评估、条件重试），比普通 RAG 更高级
4. **父子分块是进阶技巧**：父块存原文、子块做检索，通过元数据关联，提升检索精度和原文溯源
5. **跨模态检索用多模态嵌入模型**：不是 OCR 转文字再检索，而是直接用多模态嵌入模型把图文映射到同一向量空间，支持图搜图
6. **多 Agent 是系统设计能力**：主 Agent 做意图识别和路由，子 Agent 完成具体业务，体现架构设计能力
7. **记忆系统是 Agent 完整能力**：短期记忆（Redis 滑动窗口+摘要）、长期记忆（Mem0 语义+全文检索）
8. **业务系统整合是落地关键**：把现有业务系统（订单、CRM、工单）封装为 Tool call，所有公司的业务都可以做 Agent
9. **评测体系体现工程严谨性**：召回率、准确率、LLM as Judge、RAG 质量评估，是简历加分项
10. **个人技能因人而异**：每个人背景不同，只关注 Agent 相关部分就好，不用照搬别人的技能列表

## 扩展方向

- 学习如何写好技术简历（STAR 法则、量化指标、关键词匹配、ATS 优化）
- 探索 Agent 项目的更多业务场景（金融、法律、教育、医疗、制造、零售）
- 学习 Agent 系统设计（多 Agent 协作、任务分解、冲突解决、角色定义）
- 探索 RAG 高级技术（HyDE、Query2Doc、Self-RAG、Corrective RAG、RAPTOR）
- 学习知识图谱构建（实体抽取、关系抽取、图谱融合、图谱推理、GraphRAG）
- 探索多模态 Agent（图文理解、视频理解、语音交互、跨模态检索）
- 学习 Agent 评测方法（人工评测、自动评测、LLM as Judge、A/B 测试、RAGAS）
- 探索 Agent 安全与对齐（Prompt 注入防护、输出审核、价值观对齐、红队测试）
- 学习 Agent 部署与运维（Docker、K8s、监控告警、灰度发布、LangFuse/LangSmith）
- 探索 Agent 产品化（用户体验、交互设计、产品迭代、用户反馈、Human in the Loop）
